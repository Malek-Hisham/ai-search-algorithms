# AI Search & Optimization Algorithms 🤖

A collection of classic AI search algorithms and optimization problems implemented from scratch in Python.

## Algorithms Implemented

### Search Algorithms
| File | Algorithm | Problem |
|------|-----------|---------|
| `bfs_chess.py` | Breadth-First Search | Chess piece movement solver |
| `dfs_word.py` | Depth-First Search | Word puzzle solver |
| `ucs_effortpath.py` | Uniform Cost Search | Minimum effort path finder |

### Optimization Problems
| File | Algorithm | Problem |
|------|-----------|---------|
| `TSP.py` | Travelling Salesman Problem | Find shortest route visiting all cities |
| `VRP.py` | Vehicle Routing Problem | Optimize multiple vehicle routes |

### AI Game Agents
| File | Description |
|------|-------------|
| `Dungeon_final.py` | AI agent that solves a dungeon escape game |
| `puzzle_solver_final.py` | 8-puzzle / sliding puzzle solver |

## How to Run
```bash
# Run any algorithm directly
python bfs_chess.py
python TSP.py
python puzzle_solver_final.py
```

## Concepts Covered
- Graph traversal (BFS, DFS)
- Heuristic search (UCS, A*)
- Combinatorial optimization (TSP, VRP)
- Game-playing AI agents
